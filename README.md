# 🌙 Dream Research Bot

[![CI](https://github.com/lantomorroww/dream-research-bot/actions/workflows/ci.yml/badge.svg)](https://github.com/lantomorroww/dream-research-bot/actions/workflows/ci.yml)

Telegram-бот для **лонгитюдного исследования сновидений**: 7 дней подряд
задаёт участнику вопросы о ночных снах, сохраняет ответы в CSV и присылает
ежедневные напоминания в удобное для пользователя время.

> Проект написан и **активно поддерживается** мной как портфолио: показывает
> работу с асинхронным Telegram Bot API, планировщиком задач, файловым
> хранилищем, CI на GitHub Actions и упаковкой через `pyproject.toml`.

---

## ✨ Возможности

- **Согласие на участие** и описание обработки данных.
- **Сбор демографии**: номер респондента, пол, возраст, специальность.
- **7-дневный дневник снов** — каждый день:
  - описание сна **текстом или голосовым сообщением**;
  - вариант «🚫 Нет сна» — если приснилось, но не помните;
  - вариант «🤔 Помню смутно» — если помните факт сна, но не детали
    (бот спросит только впечатления, без шкал).
- **8 шкал оценки сна** (1–5):
  1. Яркость и отчётливость;
  2. Сила эмоций;
  3. Ощущение собственных действий;
  4. Память о бодрствующей жизни;
  5. Логика пространства;
  6. Течение времени;
  7. Уверенность в реальности;
  8. Ощущение тела.
- **Дополнительные сны за день** через `/extradream` — можно записать
  несколько сновидений за одну ночь.
- **Ежедневные напоминания** через `JobQueue` в удобное пользователю время
  (изменяется командой `/settime`).
- **Гибкий сброс**:
  - `/resetday` — удалить и перезаписать один конкретный день;
  - `/reset` — полностью удалить все данные пользователя.
- **Приватность**: каждый участник видит только свои данные, полный сброс
  удаляет и голосовые файлы.
